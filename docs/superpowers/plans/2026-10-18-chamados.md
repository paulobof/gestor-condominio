# Chamados Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Moradores abrem chamados (tipo/subtipo/local/descrição/até 3 fotos), o admin analisa, encaminha em lote semanal (texto gerado para copiar), registra prazo e resolve; moradores veem um mural dos encaminhados.

**Architecture:** Módulo novo `feature/complaint` (+ `complaint/catalog`) no backend Spring, copiando o padrão de fotos de `feature/classified` (MinIO fora da transação, magic-bytes, URL assinada). Domínio rico em `Complaint` (transições de status registram `ComplaintChange`, persistidas como `complaint_event` pelo service). Frontend em `features/complaints` (React + shadcn + vitest + Playwright). Tudo atrás de `app.feature.complaints.enabled` (default `false`).

**Tech Stack:** Java 21, Spring Boot 3, Hibernate 6, Flyway, PostgreSQL 16, MinIO; React 18, react-router 6, axios, vitest + RTL, Playwright, `browser-image-compression`.

**Spec:** `docs/superpowers/specs/2026-10-17-chamados-design.md`

## Global Constraints

- Soft delete via `@SQLDelete` + `@SQLRestriction("deleted_at IS NULL")` em todas as tabelas, exceto `complaint_event` (log imutável, hard delete permitido — adicionar à lista do CLAUDE.md). Nunca `CascadeType.REMOVE`.
- Lombok em entidade: `@Getter`, `@Setter(AccessLevel.PROTECTED)`, `@NoArgsConstructor(access = PROTECTED)`, `@EqualsAndHashCode(of = "id", callSuper = false)`, `@ToString(of = {...})`. Proibido `@Data`.
- Autorização por `hasAuthority('<PERMISSION>')`; nunca `hasRole`.
- `@Transactional` (Spring, `org.springframework.transaction.annotation`) só em service. Upload MinIO **fora** da transação.
- Logs sem PII: nunca logar descrição, nome, telefone; só ids.
- Fotos: máx. 3 por chamado, ≤1MB cada (1_048_576 bytes), JPEG/PNG/WEBP por magic-bytes; compressão client-side antes do envio.
- Descrição: 10–2000 caracteres (após trim). Complemento de local: ≤200. Motivo de recusa: obrigatório, ≤500. Nota de resolução: ≤500. Nome de item de catálogo: ≤80.
- Datas/“hoje” em `America/Sao_Paulo`.
- Flag: `app.feature.complaints.enabled`, default `false` (`${APP_FEATURE_COMPLAINTS_ENABLED:false}`); flag off → controllers ausentes → 404.
- Migration expand-only, cabeçalho `-- flyway:transactional=true`, PK `gen_random_uuid()`.
- UI em português; código em inglês. Touch targets ≥44px (`min-h-[44px]`). npm.
- Commits: Conventional Commits, **sem** trailer `Co-Authored-By`. Nunca `--no-verify`. Push: prefixar `JAVA_HOME=C:/Users/paulo/.jdks/corretto-21.0.7`; rodar `npm run build` no frontend antes do push.
- O working tree tem alterações não commitadas de `feature/recommendation` que **não pertencem** a este plano: nunca `git add -A`/`git add .`; adicionar arquivos explicitamente.

## Review Focus

1. **Lote confirmado depois que outro admin mexeu num chamado** (ex.: recusou entre o preview e a confirmação) → 409 e **nenhum** chamado muda de status nem lote é criado. Teste em Task 7.
2. **Item de catálogo desativado depois do chamado existir**: admin edita só a descrição de um chamado cujo tipo foi desativado → deve funcionar; trocar **para** um item inativo → 422. Teste em Task 6.
3. **Usuário sem unidade** (admin role 1 não tem unidade) → abrir chamado dá 403 `NO_UNIT`, mas o mural funciona se tiver `COMPLAINT_MANAGE`. Testes em Task 4 e Task 8.
4. **Descrição com quebras de linha / só espaços**: só espaços → 400; quebras de linha viram uma linha única no texto do lote. Testes em Task 3 e Task 7.
5. **Prazo “hoje” perto da meia-noite**: prazo igual à data de hoje em São Paulo é aceito; ontem é recusado (400 `DUE_DATE_PAST`). Teste em Task 3.

## Ajustes em relação ao spec

- `GET /board/{id}` virou o próprio `GET /api/complaints/{id}`, com a regra de visibilidade autor || `COMPLAINT_MANAGE` || no mural. Um endpoint a menos, mesma garantia.

- Resposta da síndica (Tasks 15 e 16): uma por chamado, editável pelo admin depois de encaminhar, visível no detalhe e no mural. As colunas já entram na V41.

```java
package br.com.condominio.feature.complaint;

/**
 * Erros de chamados mapeados em {@code GlobalExceptionHandler}: NOT_FOUND → 404, FORBIDDEN/NO_UNIT
 * → 403, INVALID_STATE/DUPLICATE_NAME → 409, CATALOG_INVALID → 422, demais → 400.
 */
public class ComplaintException extends RuntimeException {
  private final String code;

  public ComplaintException(String code, String message) {
    super(message);
    this.code = code;
  }

  public String getCode() {
    return code;
  }
}
```

Em `GlobalExceptionHandler`, após `handleClassified` (importar `br.com.condominio.feature.complaint.ComplaintException`):

```java
  @ExceptionHandler(ComplaintException.class)
  public ResponseEntity<ApiError> handleComplaint(ComplaintException ex) {
    HttpStatus status =
        switch (ex.getCode()) {
          case "NOT_FOUND" -> HttpStatus.NOT_FOUND;
          case "FORBIDDEN", "NO_UNIT" -> HttpStatus.FORBIDDEN;
          case "INVALID_STATE", "DUPLICATE_NAME" -> HttpStatus.CONFLICT;
          case "CATALOG_INVALID" -> HttpStatus.UNPROCESSABLE_ENTITY;
          default -> HttpStatus.BAD_REQUEST;
        };
    return ResponseEntity.status(status)
        .body(
            ApiError.of(
                status.value(),
                status.getReasonPhrase(),
                ex.getCode(),
                ex.getMessage(),
                requestId()));
  }
```

```java
import jakarta.persistence.*;

import java.util.UUID;
import lombok.*;

/** Base dos itens do catálogo de chamados: nome, ativo e ordem de exibição. */
@MappedSuperclass
@Getter
@Setter(AccessLevel.PROTECTED)
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@EqualsAndHashCode(onlyExplicitlyIncluded = true)
@ToString(onlyExplicitlyIncluded = true)
public abstract class CatalogEntry {

  @Id @GeneratedValue @EqualsAndHashCode.Include @ToString.Include private UUID id;
  @Version private Long version;

  @ToString.Include
  @Column(nullable = false, length = 80)
  private String name;

  @Column(nullable = false)
  private boolean active = true;

  @Column(name = "sort_order", nullable = false)
  private int sortOrder;

  @Column(name = "created_at", insertable = false, updatable = false)
  private Instant createdAt;

  @Column(name = "updated_at", insertable = false)
  private Instant updatedAt;

  @Column(name = "deleted_at")
  private Instant deletedAt;

  protected CatalogEntry(String name, int sortOrder) {
    this.name = name.strip();
    this.sortOrder = sortOrder;
  }

  @PreUpdate
  void onUpdate() {
    updatedAt = Instant.now();
  }

  public void update(String name, int sortOrder, boolean active) {
    this.name = name.strip();
    this.sortOrder = sortOrder;
    this.active = active;
  }
}
```

```java
package br.com.condominio.feature.complaint.catalog;

import br.com.condominio.feature.complaint.ComplaintException;
import br.com.condominio.feature.complaint.catalog.dto.*;
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
public class ComplaintCatalogService {

  private final ComplaintTypeRepository types;
  private final ComplaintSubtypeRepository subtypes;
  private final ComplaintLocationRepository locations;

  /**
   * Catálogo para o formulário (só ativos) ou para a tela de gestão (tudo). No modo "só ativos",
   * tipo sem subtipo ativo some: não há como abrir chamado nele.
   */
  @Transactional(readOnly = true)
  public CatalogView catalog(boolean includeInactive) {
    Map<UUID, List<CatalogItemView>> subsByType =
        subtypes.findAllByOrderBySortOrderAscNameAsc().stream()
            .filter(s -> includeInactive || s.isActive())
            .collect(
                Collectors.groupingBy(
                    ComplaintSubtype::getTypeId,
                    LinkedHashMap::new,
                    Collectors.mapping(CatalogItemView::of, Collectors.toList())));
    List<CatalogTypeView> typeViews =
        types.findAllByOrderBySortOrderAscNameAsc().stream()
            .filter(t -> includeInactive || t.isActive())
            .map(t -> typeView(t, subsByType.getOrDefault(t.getId(), List.of())))
            .filter(t -> includeInactive || !t.subtypes().isEmpty())
            .toList();
    List<CatalogItemView> locs =
        locations.findAllByOrderBySortOrderAscNameAsc().stream()
            .filter(l -> includeInactive || l.isActive())
            .map(CatalogItemView::of)
            .toList();
    return new CatalogView(typeViews, locs);
  }

  @Transactional
  public CatalogTypeView createType(CatalogItemRequest r) {
    String name = r.name().strip();
    if (types.existsByNameIgnoreCase(name)) throw duplicate();
    ComplaintType t = ComplaintType.create(name, r.sortOrder());
    t.update(name, r.sortOrder(), r.active());
    return typeView(types.save(t), List.of());
  }

  @Transactional
  public CatalogTypeView updateType(UUID id, CatalogItemRequest r) {
    ComplaintType t = types.findById(id).orElseThrow(ComplaintCatalogService::notFound);
    String name = r.name().strip();
    if (types.existsByNameIgnoreCaseAndIdNot(name, id)) throw duplicate();
    t.update(name, r.sortOrder(), r.active());
    List<CatalogItemView> subs =
        subtypes.findByTypeIdOrderBySortOrderAscNameAsc(id).stream()
            .map(CatalogItemView::of)
            .toList();
    return typeView(t, subs);
  }

  @Transactional
  public CatalogItemView createSubtype(UUID typeId, CatalogItemRequest r) {
    types.findById(typeId).orElseThrow(ComplaintCatalogService::notFound);
    String name = r.name().strip();
    if (subtypes.existsByTypeIdAndNameIgnoreCase(typeId, name)) throw duplicate();
    ComplaintSubtype s = ComplaintSubtype.create(typeId, name, r.sortOrder());
    s.update(name, r.sortOrder(), r.active());
    return CatalogItemView.of(subtypes.save(s));
  }

  @Transactional
  public CatalogItemView updateSubtype(UUID id, CatalogItemRequest r) {
    ComplaintSubtype s = subtypes.findById(id).orElseThrow(ComplaintCatalogService::notFound);
    String name = r.name().strip();
    if (subtypes.existsByTypeIdAndNameIgnoreCaseAndIdNot(s.getTypeId(), name, id)) {
      throw duplicate();
    }
    s.update(name, r.sortOrder(), r.active());
    return CatalogItemView.of(s);
  }

  @Transactional
  public CatalogItemView createLocation(CatalogItemRequest r) {
    String name = r.name().strip();
    if (locations.existsByNameIgnoreCase(name)) throw duplicate();
    ComplaintLocation l = ComplaintLocation.create(name, r.sortOrder());
    l.update(name, r.sortOrder(), r.active());
    return CatalogItemView.of(locations.save(l));
  }

  @Transactional
  public CatalogItemView updateLocation(UUID id, CatalogItemRequest r) {
    ComplaintLocation l = locations.findById(id).orElseThrow(ComplaintCatalogService::notFound);
    String name = r.name().strip();
    if (locations.existsByNameIgnoreCaseAndIdNot(name, id)) throw duplicate();
    l.update(name, r.sortOrder(), r.active());
    return CatalogItemView.of(l);
  }

  /**
   * Valida a escolha de tipo/subtipo/local. {@code grandfathered}: ids que o chamado já usa — um
   * item desativado depois continua aceito para ele, senão o admin não conseguiria editar só a
   * descrição de um chamado antigo.
   */
  @Transactional(readOnly = true)
  public void requireUsable(
      UUID typeId, UUID subtypeId, UUID locationId, Set<UUID> grandfathered) {
    ComplaintType t = types.findById(typeId).orElseThrow(() -> invalid("Tipo inexistente."));
    ComplaintSubtype s =
        subtypes.findById(subtypeId).orElseThrow(() -> invalid("Subtipo inexistente."));
    ComplaintLocation l =
        locations.findById(locationId).orElseThrow(() -> invalid("Local inexistente."));
    if (!s.getTypeId().equals(t.getId())) {
      throw invalid("O subtipo não pertence ao tipo escolhido.");
    }
    for (CatalogEntry e : List.<CatalogEntry>of(t, s, l)) {
      if (!e.isActive() && !grandfathered.contains(e.getId())) {
        throw invalid("\"" + e.getName() + "\" não está mais disponível.");
      }
    }
  }

  @Transactional(readOnly = true)
  public CatalogIndex index(Set<UUID> typeIds, Set<UUID> subtypeIds, Set<UUID> locationIds) {
    return new CatalogIndex(
        byId(types.findAllById(typeIds)),
        byId(subtypes.findAllById(subtypeIds)),
        byId(locations.findAllById(locationIds)));
  }

  private static <T extends CatalogEntry> Map<UUID, T> byId(List<T> list) {
    return list.stream().collect(Collectors.toMap(CatalogEntry::getId, Function.identity()));
  }

  private static CatalogTypeView typeView(ComplaintType t, List<CatalogItemView> subs) {
    return new CatalogTypeView(t.getId(), t.getName(), t.isActive(), t.getSortOrder(), subs);
  }

  private static ComplaintException notFound() {
    return new ComplaintException("NOT_FOUND", "Item do catálogo não encontrado.");
  }

  private static ComplaintException duplicate() {
    return new ComplaintException("DUPLICATE_NAME", "Já existe um item com esse nome.");
  }

  private static ComplaintException invalid(String msg) {
    return new ComplaintException("CATALOG_INVALID", msg);
  }
}
```

```java
package br.com.condominio.feature.complaint;

import jakarta.persistence.*;
import java.time.Instant;
import java.time.LocalDate;
import java.util.*;
import lombok.*;
import org.hibernate.annotations.DynamicInsert;
import org.hibernate.annotations.Generated;
import org.hibernate.annotations.SQLDelete;
import org.hibernate.annotations.SQLRestriction;

@Entity
@Table(name = "complaint")
@DynamicInsert
@Getter
@Setter(AccessLevel.PROTECTED)
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@EqualsAndHashCode(of = "id", callSuper = false)
@ToString(of = {"id", "code", "status"})
@SQLDelete(sql = "UPDATE complaint SET deleted_at = now() WHERE id = ? AND version = ?")
@SQLRestriction("deleted_at IS NULL")
public class Complaint {

  private static final int DESCRIPTION_MIN = 10;
  private static final int DESCRIPTION_MAX = 2000;
  private static final int DETAIL_MAX = 200;
  private static final int REASON_MAX = 500;

  @Id @GeneratedValue private UUID id;
  @Version private Long version;

  /** Número curto exibido como #123; vem da sequence no INSERT. */
  @Generated
  @Column(insertable = false, updatable = false)
  private Long code;

  @Column(name = "author_user_id", nullable = false, updatable = false)
  private UUID authorUserId;

  @Column(name = "author_unit_id", nullable = false, updatable = false)
  private UUID authorUnitId;

  @Column(name = "type_id", nullable = false)
  private UUID typeId;

  @Column(name = "subtype_id", nullable = false)
  private UUID subtypeId;

  @Column(name = "location_id", nullable = false)
  private UUID locationId;

  @Column(name = "location_detail", length = DETAIL_MAX)
  private String locationDetail;

  @Column(nullable = false, length = DESCRIPTION_MAX)
  private String description;

  @Enumerated(EnumType.STRING)
  @Column(nullable = false, length = 20)
  private ComplaintStatus status;

  @Column(name = "due_date")
  private LocalDate dueDate;

  @Column(name = "rejection_reason", length = REASON_MAX)
  private String rejectionReason;

  @Column(name = "resolution_note", length = REASON_MAX)
  private String resolutionNote;

  @Column(name = "batch_id")
  private UUID batchId;

  @Column(name = "forwarded_at")
  private Instant forwardedAt;

  @Column(name = "resolved_at")
  private Instant resolvedAt;

  @Column(name = "created_at", insertable = false, updatable = false)
  private Instant createdAt;

  @Column(name = "updated_at", insertable = false)
  private Instant updatedAt;

  @Column(name = "deleted_at")
  private Instant deletedAt;

  @Transient
  @Getter(AccessLevel.NONE)
  private List<ComplaintChange> changes = new ArrayList<>();

  @PreUpdate
  void onUpdate() {
    updatedAt = Instant.now();
  }

  public static Complaint create(UUID authorId, UUID unitId, ComplaintFields f) {
    Complaint c = new Complaint();
    c.authorUserId = authorId;
    c.authorUnitId = unitId;
    c.apply(f);
    c.status = ComplaintStatus.OPEN;
    c.record(ComplaintEventKind.CREATED, authorId, null, ComplaintStatus.OPEN.name());
    return c;
  }

  public void editByAuthor(UUID actor, ComplaintFields f) {
    requireAuthor(actor);
    requireStatus(ComplaintStatus.OPEN);
    record(ComplaintEventKind.EDITED, actor, null, apply(f));
  }

  public void cancelByAuthor(UUID actor) {
    requireAuthor(actor);
    requireStatus(ComplaintStatus.OPEN);
    record(ComplaintEventKind.CANCELLED, actor, status.name(), null);
  }

  public void startReview(UUID actor) {
    transition(actor, ComplaintStatus.IN_REVIEW, ComplaintStatus.OPEN);
  }

  public void editByAdmin(UUID actor, ComplaintFields f) {
    requireStatus(ComplaintStatus.IN_REVIEW, ComplaintStatus.READY);
    record(ComplaintEventKind.EDITED, actor, null, apply(f));
  }

  public void markReady(UUID actor) {
    transition(actor, ComplaintStatus.READY, ComplaintStatus.IN_REVIEW);
  }

  public void reopenReview(UUID actor) {
    transition(actor, ComplaintStatus.IN_REVIEW, ComplaintStatus.READY);
  }

  public void reject(UUID actor, String reason) {
    String r = reason == null ? "" : reason.strip();
    if (r.isEmpty() || r.length() > REASON_MAX) {
      throw invalidInput("Informe o motivo da recusa (até 500 caracteres).");
    }
    transition(
        actor,
        ComplaintStatus.REJECTED,
        ComplaintStatus.OPEN,
        ComplaintStatus.IN_REVIEW,
        ComplaintStatus.READY);
    rejectionReason = r;
  }

  public void forward(UUID actor, UUID batchId, Instant now) {
    transition(actor, ComplaintStatus.FORWARDED, ComplaintStatus.READY);
    this.batchId = batchId;
    this.forwardedAt = now;
  }

  public void setDueDate(UUID actor, LocalDate due, LocalDate today) {
    requireStatus(ComplaintStatus.FORWARDED);
    if (due == null) throw invalidInput("Informe o prazo.");
    if (due.isBefore(today)) {
      throw new ComplaintException("DUE_DATE_PAST", "O prazo não pode estar no passado.");
    }
    String from = dueDate == null ? null : dueDate.toString();
    dueDate = due;
    record(ComplaintEventKind.DUE_DATE_SET, actor, from, due.toString());
  }

  public void resolve(UUID actor, String note, Instant now) {
    String n = note == null || note.isBlank() ? null : note.strip();
    if (n != null && n.length() > REASON_MAX) {
      throw invalidInput("A observação deve ter até 500 caracteres.");
    }
    transition(actor, ComplaintStatus.RESOLVED, ComplaintStatus.FORWARDED);
    resolutionNote = n;
    resolvedAt = now;
  }

  public void requirePhotoEditableBy(UUID actor) {
    requireAuthor(actor);
    requireStatus(ComplaintStatus.OPEN);
  }

  public boolean isAuthor(UUID userId) {
    return authorUserId.equals(userId);
  }

  /** No mural: já encaminhado à síndica (ou resolvido depois disso). */
  public boolean isOnBoard() {
    return status == ComplaintStatus.FORWARDED || status == ComplaintStatus.RESOLVED;
  }

  public boolean isVisibleTo(UUID userId, boolean canManage) {
    return canManage || isAuthor(userId) || isOnBoard();
  }

  /** Itens de catálogo já em uso — aceitos mesmo se desativados depois. */
  public Set<UUID> usedCatalogIds() {
    return Set.of(typeId, subtypeId, locationId);
  }

  public List<ComplaintChange> drainChanges() {
    List<ComplaintChange> out = List.copyOf(changes);
    changes.clear();
    return out;
  }

  /** Aplica os campos e devolve os nomes dos campos alterados (para o evento, sem conteúdo). */
  private String apply(ComplaintFields f) {
    String desc = f.description() == null ? "" : f.description().strip();
    if (desc.length() < DESCRIPTION_MIN || desc.length() > DESCRIPTION_MAX) {
      throw invalidInput("A descrição deve ter entre 10 e 2000 caracteres.");
    }
    String detail =
        f.locationDetail() == null || f.locationDetail().isBlank()
            ? null
            : f.locationDetail().strip();
    if (detail != null && detail.length() > DETAIL_MAX) {
      throw invalidInput("O complemento do local deve ter até 200 caracteres.");
    }
    List<String> changed = new ArrayList<>();
    if (!Objects.equals(typeId, f.typeId())) changed.add("type");
    if (!Objects.equals(subtypeId, f.subtypeId())) changed.add("subtype");
    if (!Objects.equals(locationId, f.locationId())) changed.add("location");
    if (!Objects.equals(locationDetail, detail)) changed.add("locationDetail");
    if (!Objects.equals(description, desc)) changed.add("description");
    typeId = f.typeId();
    subtypeId = f.subtypeId();
    locationId = f.locationId();
    locationDetail = detail;
    description = desc;
    return String.join(",", changed);
  }

  private void transition(UUID actor, ComplaintStatus to, ComplaintStatus... allowedFrom) {
    requireStatus(allowedFrom);
    ComplaintStatus from = status;
    status = to;
    record(ComplaintEventKind.STATUS_CHANGED, actor, from.name(), to.name());
  }

  private void requireStatus(ComplaintStatus... allowed) {
    if (!Arrays.asList(allowed).contains(status)) {
      throw new ComplaintException(
          "INVALID_STATE", "Ação não permitida para chamado com status " + status + ".");
    }
  }

  /** Não-autor recebe "não encontrado": não revela que o chamado existe. */
  private void requireAuthor(UUID actor) {
    if (!isAuthor(actor)) {
      throw new ComplaintException("NOT_FOUND", "Chamado não encontrado.");
    }
  }

  private void record(ComplaintEventKind kind, UUID actor, String from, String to) {
    changes.add(new ComplaintChange(kind, actor, from, to));
  }

  private static ComplaintException invalidInput(String msg) {
    return new ComplaintException("INVALID_INPUT", msg);
  }
}
```

```java
package br.com.condominio.feature.complaint;

import br.com.condominio.feature.complaint.catalog.CatalogIndex;
import br.com.condominio.feature.complaint.catalog.ComplaintCatalogService;
import br.com.condominio.feature.complaint.dto.ComplaintPhotoView;
import br.com.condominio.feature.complaint.dto.ComplaintView;
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Component;

/** Monta {@link ComplaintView} em lote: 1 query de catálogo e 1 de fotos por página. */
@Component
@RequiredArgsConstructor
public class ComplaintViewAssembler {

  private final ComplaintCatalogService catalog;
  private final ComplaintPhotoRepository photos;

  public ComplaintView toView(Complaint c, UUID viewerId) {
    return toViews(List.of(c), viewerId).get(0);
  }

  public List<ComplaintView> toViews(List<Complaint> list, UUID viewerId) {
    if (list.isEmpty()) return List.of();
    CatalogIndex idx =
        catalog.index(
            collect(list, Complaint::getTypeId),
            collect(list, Complaint::getSubtypeId),
            collect(list, Complaint::getLocationId));
    Map<UUID, List<ComplaintPhotoView>> photosById =
        photos.findByComplaintIdInOrderByOrdering(collect(list, Complaint::getId)).stream()
            .collect(
                Collectors.groupingBy(
                    ComplaintPhoto::getComplaintId,
                    Collectors.mapping(ComplaintPhotoView::of, Collectors.toList())));
    return list.stream()
        .map(
            c ->
                ComplaintView.of(
                    c,
                    idx,
                    photosById.getOrDefault(c.getId(), List.of()),
                    c.isAuthor(viewerId) && c.getStatus() == ComplaintStatus.OPEN))
        .toList();
  }

  private static Set<UUID> collect(List<Complaint> list, Function<Complaint, UUID> f) {
    return list.stream().map(f).collect(Collectors.toSet());
  }
}
```

```java
package br.com.condominio.feature.complaint;

import br.com.condominio.feature.complaint.catalog.ComplaintCatalogService;
import br.com.condominio.feature.complaint.dto.ComplaintView;
import java.util.List;
import java.util.Set;
import java.util.UUID;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
public class ComplaintService {

  private final ComplaintRepository repo;
  private final ComplaintCatalogService catalog;
  private final ComplaintEventWriter events;
  private final ComplaintViewAssembler views;

  /** saveAndFlush: o {@code code} vem da sequence no INSERT e precisa estar na resposta. */
  @Transactional
  public ComplaintView create(UUID userId, UUID unitId, ComplaintFields f) {
    if (unitId == null) {
      throw new ComplaintException("NO_UNIT", "Só moradores com unidade podem abrir chamados.");
    }
    catalog.requireUsable(f.typeId(), f.subtypeId(), f.locationId(), Set.of());
    Complaint c = repo.saveAndFlush(Complaint.create(userId, unitId, f));
    events.flush(c);
    return views.toView(c, userId);
  }

  @Transactional(readOnly = true)
  public List<ComplaintView> mine(UUID userId) {
    return views.toViews(repo.findByAuthorUserIdOrderByCreatedAtDesc(userId), userId);
  }

  @Transactional(readOnly = true)
  public ComplaintView get(UUID id, UUID userId, boolean canManage) {
    Complaint c = load(id);
    if (!c.isVisibleTo(userId, canManage)) throw notFound();
    return views.toView(c, userId);
  }

  @Transactional
  public ComplaintView update(UUID id, UUID userId, ComplaintFields f) {
    Complaint c = load(id);
    if (!c.isAuthor(userId)) throw notFound();
    catalog.requireUsable(f.typeId(), f.subtypeId(), f.locationId(), c.usedCatalogIds());
    c.editByAuthor(userId, f);
    events.flush(c);
    return views.toView(c, userId);
  }

  @Transactional
  public void cancel(UUID id, UUID userId) {
    Complaint c = load(id);
    c.cancelByAuthor(userId);
    events.flush(c);
    repo.delete(c);
  }

  Complaint load(UUID id) {
    return repo.findById(id).orElseThrow(ComplaintService::notFound);
  }

  static ComplaintException notFound() {
    return new ComplaintException("NOT_FOUND", "Chamado não encontrado.");
  }
}
```

```java
package br.com.condominio.feature.complaint;

import br.com.condominio.feature.complaint.dto.ComplaintPhotoView;
import br.com.condominio.storage.FileStorage;
import br.com.condominio.storage.MagicBytesValidator;
import br.com.condominio.storage.MinioProperties;
import java.io.IOException;
import java.io.InputStream;
import java.time.Duration;
import java.util.UUID;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.multipart.MultipartFile;

@Service
@RequiredArgsConstructor
public class ComplaintPhotoService {

  static final long MAX_PHOTO_BYTES = 1_048_576L;
  static final int MAX_PHOTOS = 3;

  private final ComplaintRepository repo;
  private final ComplaintPhotoRepository photoRepo;
  private final FileStorage storage;
  private final MagicBytesValidator magicBytes;
  private final MinioProperties props;
  private final ComplaintEventWriter events;

  /**
   * NÃO transacional: o upload pro MinIO acontece fora de transação (CLAUDE.md). Mesmo trade-off
   * de classificados: checagem de limite e save não são atômicos; o índice único parcial
   * (complaint_id, ordering) impede linha duplicada.
   */
  public ComplaintPhotoView addPhoto(UUID id, UUID actor, MultipartFile file) {
    Complaint c = load(id);
    c.requirePhotoEditableBy(actor);
    if (photoRepo.countByComplaintId(id) >= MAX_PHOTOS) {
      throw new ComplaintException("PHOTO_LIMIT", "Máximo de 3 fotos por chamado.");
    }
    if (file.getSize() > MAX_PHOTO_BYTES) {
      throw new ComplaintException("PHOTO_TOO_LARGE", "Foto deve ter no máximo 1MB.");
    }
    String mime;
    try (InputStream in = file.getInputStream()) {
      mime = magicBytes.detect(in);
    } catch (IOException e) {
      throw new ComplaintException("PHOTO_READ_FAILED", "Falha ao ler a imagem.");
    }
    if (!magicBytes.isAcceptedForPhoto(mime)) {
      throw new ComplaintException("PHOTO_TYPE_INVALID", "Aceitamos JPG, PNG ou WEBP.");
    }
    String objectKey;
    try (InputStream in = file.getInputStream()) {
      objectKey = storage.upload(props.getBucketComplaints(), in, file.getSize(), mime);
    } catch (IOException e) {
      throw new ComplaintException("PHOTO_UPLOAD_FAILED", "Falha ao enviar a imagem.");
    }
    int ordering = photoRepo.maxOrdering(id) + 1;
    ComplaintPhoto saved =
        photoRepo.save(ComplaintPhoto.create(id, objectKey, mime, file.getSize(), ordering));
    events.record(
        id,
        new ComplaintChange(ComplaintEventKind.PHOTO_ADDED, actor, null, saved.getId().toString()));
    return ComplaintPhotoView.of(saved);
  }

  @Transactional
  public void removePhoto(UUID id, UUID photoId, UUID actor) {
    Complaint c = load(id);
    c.requirePhotoEditableBy(actor);
    ComplaintPhoto p = photoRepo.findByIdAndComplaintId(photoId, id).orElseThrow(this::photoNotFound);
    photoRepo.delete(p);
    events.record(
        id, new ComplaintChange(ComplaintEventKind.PHOTO_REMOVED, actor, photoId.toString(), null));
  }

  @Transactional(readOnly = true)
  public String photoUrl(UUID id, UUID photoId, UUID actor, boolean canManage) {
    Complaint c = load(id);
    if (!c.isVisibleTo(actor, canManage)) throw ComplaintService.notFound();
    ComplaintPhoto p = photoRepo.findByIdAndComplaintId(photoId, id).orElseThrow(this::photoNotFound);
    return storage.presignedGetUrl(
        props.getBucketComplaints(),
        p.getObjectKey(),
        Duration.ofSeconds(props.getPresignedTtlPhotosSeconds()));
  }

  private Complaint load(UUID id) {
    return repo.findById(id).orElseThrow(ComplaintService::notFound);
  }

  private ComplaintException photoNotFound() {
    return new ComplaintException("NOT_FOUND", "Foto não encontrada.");
  }
}
```

```java
@Service
@RequiredArgsConstructor
public class ComplaintAdminService {

  public static final ZoneId ZONE = ZoneId.of("America/Sao_Paulo");
  private static final Set<ComplaintStatus> PENDING =
      EnumSet.of(ComplaintStatus.OPEN, ComplaintStatus.IN_REVIEW, ComplaintStatus.READY);

  private final ComplaintRepository repo;
  private final ComplaintCatalogService catalog;
  private final ComplaintEventWriter events;
  private final ComplaintEventRepository eventRepo;
  private final ComplaintViewAssembler views;
  private final UserRepository users;
  private final UnitRepository units;
  private final Clock clock;

  @Transactional(readOnly = true)
  public Page<ComplaintAdminView> queue(Set<ComplaintStatus> statuses, int page, int size) {
    Set<ComplaintStatus> filter = statuses == null || statuses.isEmpty() ? PENDING : statuses;
    PageRequest pr =
        PageRequest.of(
            Math.max(page, 0),
            Math.min(Math.max(size, 1), 100),
            Sort.by(Sort.Direction.ASC, "createdAt"));
    Page<Complaint> result = repo.findAll(ComplaintSpecs.statusIn(filter), pr);
    List<Complaint> content = result.getContent();
    List<ComplaintView> complaintViews = views.toViews(content, null);
    Map<UUID, User> authors = usersOf(content.stream().map(Complaint::getAuthorUserId));
    Map<UUID, Unit> unitIdx =
        units.findAllById(content.stream().map(Complaint::getAuthorUnitId).toList()).stream()
            .collect(Collectors.toMap(Unit::getId, Function.identity()));
    List<ComplaintAdminView> rows = new ArrayList<>();
    for (int i = 0; i < content.size(); i++) {
      Complaint c = content.get(i);
      rows.add(
          new ComplaintAdminView(
              complaintViews.get(i),
              nameOf(authors.get(c.getAuthorUserId())),
              codeOf(unitIdx.get(c.getAuthorUnitId()))));
    }
    return new PageImpl<>(rows, pr, result.getTotalElements());
  }

  @Transactional(readOnly = true)
  public ComplaintAdminDetailView detail(UUID id) {
    return detailOf(load(id));
  }

  @Transactional
  public ComplaintAdminDetailView startReview(UUID id, UUID actor) {
    return act(id, c -> c.startReview(actor));
  }

  @Transactional
  public ComplaintAdminDetailView markReady(UUID id, UUID actor) {
    return act(id, c -> c.markReady(actor));
  }

  @Transactional
  public ComplaintAdminDetailView reopenReview(UUID id, UUID actor) {
    return act(id, c -> c.reopenReview(actor));
  }

  @Transactional
  public ComplaintAdminDetailView reject(UUID id, UUID actor, String reason) {
    return act(id, c -> c.reject(actor, reason));
  }

  @Transactional
  public ComplaintAdminDetailView edit(UUID id, UUID actor, ComplaintFields f) {
    return act(
        id,
        c -> {
          catalog.requireUsable(f.typeId(), f.subtypeId(), f.locationId(), c.usedCatalogIds());
          c.editByAdmin(actor, f);
        });
  }

  @Transactional
  public ComplaintAdminDetailView setDueDate(UUID id, UUID actor, LocalDate due) {
    LocalDate today = LocalDate.ofInstant(clock.now(), ZONE);
    return act(id, c -> c.setDueDate(actor, due, today));
  }

  @Transactional
  public ComplaintAdminDetailView resolve(UUID id, UUID actor, String note) {
    return act(id, c -> c.resolve(actor, note, clock.now()));
  }

  private ComplaintAdminDetailView act(UUID id, Consumer<Complaint> action) {
    Complaint c = load(id);
    action.accept(c);
    events.flush(c);
    return detailOf(c);
  }

  private ComplaintAdminDetailView detailOf(Complaint c) {
    List<ComplaintEvent> history = eventRepo.findByComplaintIdOrderByCreatedAtAsc(c.getId());
    Map<UUID, User> people =
        usersOf(
            java.util.stream.Stream.concat(
                java.util.stream.Stream.of(c.getAuthorUserId()),
                history.stream().map(ComplaintEvent::getActorUserId)));
    String unitCode =
        units.findAllById(List.of(c.getAuthorUnitId())).stream()
            .findFirst()
            .map(Unit::getCode)
            .orElse(null);
    List<ComplaintEventView> eventViews =
        history.stream()
            .map(
                e ->
                    new ComplaintEventView(
                        e.getKind(),
                        nameOf(people.get(e.getActorUserId())),
                        e.getFromValue(),
                        e.getToValue(),
                        e.getCreatedAt()))
            .toList();
    return new ComplaintAdminDetailView(
        views.toView(c, null), nameOf(people.get(c.getAuthorUserId())), unitCode, eventViews);
  }

  private Map<UUID, User> usersOf(java.util.stream.Stream<UUID> ids) {
    Set<UUID> set = ids.collect(Collectors.toSet());
    return users.findAllById(set).stream()
        .collect(Collectors.toMap(User::getId, Function.identity()));
  }

  private static String nameOf(User u) {
    return u == null ? null : u.getFullName();
  }

  private static String codeOf(Unit u) {
    return u == null ? null : u.getCode();
  }

  private Complaint load(UUID id) {
    return repo.findById(id).orElseThrow(ComplaintService::notFound);
  }
}
```

```java
/** Texto do lote semanal para a síndica (copiar/colar). Puro: sem I/O, sem relógio. */
@Component
public class ComplaintBatchTextRenderer {

  private static final DateTimeFormatter BR = DateTimeFormatter.ofPattern("dd/MM/yyyy");
  private static final Locale PT_BR = Locale.forLanguageTag("pt-BR");

  public String render(LocalDate date, List<BatchLine> lines) {
    List<BatchLine> sorted =
        lines.stream()
            .sorted(
                Comparator.comparingInt(BatchLine::typeOrder)
                    .thenComparing(BatchLine::typeName)
                    .thenComparingLong(BatchLine::code))
            .toList();
    int n = sorted.size();
    StringBuilder sb = new StringBuilder("Chamados — HELBOR TRILOGY HOME\n");
    sb.append("Lote de ")
        .append(BR.format(date))
        .append(" (")
        .append(n)
        .append(n == 1 ? " chamado" : " chamados")
        .append(")\n");
    String currentType = null;
    int i = 0;
    for (BatchLine l : sorted) {
      if (!l.typeName().equals(currentType)) {
        sb.append('\n').append(l.typeName().toUpperCase(PT_BR)).append('\n');
        currentType = l.typeName();
      }
      sb.append(++i)
          .append(". #")
          .append(l.code())
          .append(' ')
          .append(l.subtypeName())
          .append(" — ")
          .append(l.locationName());
      if (l.locationDetail() != null) sb.append(" (").append(l.locationDetail()).append(')');
      sb.append("\n   ").append(oneLine(l.description())).append('\n');
    }
    return sb.toString().stripTrailing();
  }

  private static String oneLine(String s) {
    return s.strip().replaceAll("\\s+", " ");
  }
}
```

```java
package br.com.condominio.feature.complaint.batch;

import br.com.condominio.feature.complaint.*;
import br.com.condominio.feature.complaint.batch.dto.BatchPreview;
import br.com.condominio.feature.complaint.batch.dto.ComplaintBatchView;
import br.com.condominio.feature.complaint.catalog.CatalogIndex;
import br.com.condominio.feature.complaint.catalog.ComplaintCatalogService;
import br.com.condominio.feature.user.User;
import br.com.condominio.feature.user.UserRepository;
import br.com.condominio.shared.time.Clock;
import java.time.Instant;
import java.time.LocalDate;
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
@RequiredArgsConstructor
public class ComplaintBatchService {

  private final ComplaintRepository repo;
  private final ComplaintBatchRepository batches;
  private final ComplaintCatalogService catalog;
  private final ComplaintEventWriter events;
  private final UserRepository users;
  private final Clock clock;
  private final ComplaintBatchTextRenderer renderer;

  @Transactional(readOnly = true)
  public BatchPreview preview(List<UUID> ids) {
    List<Complaint> list = loadReady(ids);
    return new BatchPreview(render(list, today(clock.now())), list.size());
  }

  /**
   * Tudo ou nada: valida todos antes de mexer em qualquer um. Se outro admin alterou um chamado
   * entre o preview e a confirmação, ou ele já não está READY (409), ou o @Version estoura no
   * commit (409 CONCURRENT_MODIFICATION). Nos dois casos a transação inteira volta.
   */
  @Transactional
  public ComplaintBatchView create(List<UUID> ids, UUID actor) {
    List<Complaint> list = loadReady(ids);
    Instant now = clock.now();
    String text = render(list, today(now));
    ComplaintBatch batch = batches.save(ComplaintBatch.create(actor, now, text, list.size()));
    for (Complaint c : list) {
      c.forward(actor, batch.getId(), now);
      events.flush(c);
    }
    return view(batch, namesOf(Set.of(actor)));
  }

  @Transactional(readOnly = true)
  public List<ComplaintBatchView> list() {
    List<ComplaintBatch> all = batches.findAllByOrderBySentAtDesc();
    Map<UUID, String> names =
        namesOf(all.stream().map(ComplaintBatch::getSentByUserId).collect(Collectors.toSet()));
    return all.stream().map(b -> view(b, names)).toList();
  }

  private List<Complaint> loadReady(List<UUID> ids) {
    Set<UUID> distinct = new LinkedHashSet<>(ids);
    List<Complaint> list = repo.findAllById(distinct);
    if (list.size() != distinct.size()) {
      throw new ComplaintException("NOT_FOUND", "Algum chamado do lote não foi encontrado.");
    }
    for (Complaint c : list) {
      if (c.getStatus() != ComplaintStatus.READY) {
        throw new ComplaintException(
            "INVALID_STATE",
            "O chamado #" + c.getCode() + " não está mais pronto para encaminhar. Recarregue.");
      }
    }
    return list;
  }

  private String render(List<Complaint> list, LocalDate date) {
    CatalogIndex idx =
        catalog.index(
            list.stream().map(Complaint::getTypeId).collect(Collectors.toSet()),
            list.stream().map(Complaint::getSubtypeId).collect(Collectors.toSet()),
            list.stream().map(Complaint::getLocationId).collect(Collectors.toSet()));
    List<BatchLine> lines =
        list.stream()
            .map(
                c ->
                    new BatchLine(
                        c.getCode() == null ? 0 : c.getCode(),
                        idx.typeName(c.getTypeId()),
                        idx.typeOrder(c.getTypeId()),
                        idx.subtypeName(c.getSubtypeId()),
                        idx.locationName(c.getLocationId()),
                        c.getLocationDetail(),
                        c.getDescription()))
            .toList();
    return renderer.render(date, lines);
  }

  private static LocalDate today(Instant now) {
    return LocalDate.ofInstant(now, ComplaintAdminService.ZONE);
  }

  private Map<UUID, String> namesOf(Set<UUID> ids) {
    return users.findAllById(ids).stream()
        .collect(Collectors.toMap(User::getId, User::getFullName));
  }

  private static ComplaintBatchView view(ComplaintBatch b, Map<UUID, String> names) {
    return new ComplaintBatchView(
        b.getId(),
        b.getSentAt(),
        names.get(b.getSentByUserId()),
        b.getComplaintCount(),
        b.getRenderedText());
  }
}
```

```java
      EnumSet.of(ComplaintStatus.FORWARDED, ComplaintStatus.RESOLVED);

  /**
   * Mural: só o que já foi encaminhado. Ordenar por status ASC põe FORWARDED antes de RESOLVED
   * porque a ordem alfabética coincide com a desejada; se um status novo entrar no mural, trocar

  @Transactional(readOnly = true)
  public Page<ComplaintView> board(
      UUID viewerId,
      UUID unitId,
      boolean canManage,
      UUID typeId,
      UUID locationId,
      ComplaintStatus status,
      int page,
      int size) {
    if (unitId == null && !canManage) {
      throw new ComplaintException("NO_UNIT", "O mural é exclusivo para moradores.");
    }
    if (status != null && !BOARD.contains(status)) {
      throw new ComplaintException("INVALID_INPUT", "Filtro de status inválido para o mural.");
    }
    Specification<Complaint> spec =
        Specification.where(ComplaintSpecs.statusIn(status == null ? BOARD : Set.of(status)))
            .and(ComplaintSpecs.typeIs(typeId))
            .and(ComplaintSpecs.locationIs(locationId));
    PageRequest pr =
        PageRequest.of(
            Math.max(page, 0),
            Math.min(Math.max(size, 1), 100),
            Sort.by(Sort.Order.asc("status"), Sort.Order.desc("forwardedAt")));
    Page<Complaint> result = repo.findAll(spec, pr);
    List<ComplaintView> content = views.toViews(result.getContent(), viewerId);
    return new PageImpl<>(content, pr, result.getTotalElements());
```

```tsx
export interface CatalogSelection {

  locationId: string;
}

/** Itens já usados pelo chamado que podem ter sido desativados no catálogo. */
export interface CatalogFallback {
  typeId?: string;
  typeName?: string;
  subtypeId?: string;
  subtypeName?: string;
  locationId?: string;
  locationName?: string;

const SELECT =
  'flex h-11 w-full rounded-md border border-input bg-background px-3 py-2 text-sm ring-offset-background focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2';

interface Props {
  catalog: Catalog;
  value: CatalogSelection;
  onChange: (v: CatalogSelection) => void;
  fallback?: CatalogFallback;
}

export function CatalogSelects({ catalog, value, onChange, fallback }: Props) {
  const type = catalog.types.find((t) => t.id === value.typeId);
  const subtypes = type?.subtypes ?? [];
  const typeMissing = !!value.typeId && !type && fallback?.typeId === value.typeId;
  const subtypeMissing =
    !!value.subtypeId &&
    !subtypes.some((s) => s.id === value.subtypeId) &&
    fallback?.subtypeId === value.subtypeId;
  const locationMissing =
    !!value.locationId &&
    !catalog.locations.some((l) => l.id === value.locationId) &&
    fallback?.locationId === value.locationId;

  return (
    <div className="grid gap-4 sm:grid-cols-3">
      <div className="space-y-2">
        <Label htmlFor="complaint-type">Tipo</Label>
        <select
          id="complaint-type"
          className={SELECT}
          value={value.typeId}
          onChange={(e) => onChange({ ...value, typeId: e.target.value, subtypeId: '' })}
          required
        >
          <option value="">Selecione…</option>
          {typeMissing && <option value={value.typeId}>{fallback?.typeName} (inativo)</option>}
          {catalog.types.map((t) => (
            <option key={t.id} value={t.id}>

          disabled={!value.typeId}
          required
        >
          <option value="">Selecione…</option>
          {subtypeMissing && (
            <option value={value.subtypeId}>{fallback?.subtypeName} (inativo)</option>
          )}
```

```tsx
import { useEffect, useState } from 'react';
import { getComplaintPhotoUrl, type ComplaintPhoto } from '../api/complaintsApi';

/** Galeria somente-leitura; URLs assinadas são buscadas uma a uma (falha individual é ignorada). */
export function ComplaintPhotos({
  complaintId,
  photos,
}: {
  complaintId: string;
  photos: ComplaintPhoto[];
}) {
  const [urls, setUrls] = useState<Record<string, string>>({});

  useEffect(() => {
    let active = true;
    photos.forEach((p) => {
      getComplaintPhotoUrl(complaintId, p.id)
        .then((url) => active && setUrls((prev) => ({ ...prev, [p.id]: url })))
        .catch(() => {
          /* ignora foto individual */
        });
    });
    return () => {
      active = false;
    };
  }, [complaintId, photos]);

  if (photos.length === 0) return null;
  return (
    <ul className="grid grid-cols-3 gap-2">
      {photos.map((p, i) => (
        <li key={p.id} className="aspect-square overflow-hidden rounded-md border bg-muted">
          {urls[p.id] && (
            <a href={urls[p.id]} target="_blank" rel="noreferrer">
              <img
                src={urls[p.id]}
                alt={`Foto ${i + 1} do chamado`}
                className="h-full w-full object-cover"
                referrerPolicy="no-referrer"
              />
            </a>
          )}
        </li>
      ))}
    </ul>
  );
}
```

```tsx
import { useEffect, useRef, useState } from 'react';
import { Link, useNavigate, useParams } from 'react-router-dom';
import { toast } from 'sonner';
import imageCompression from 'browser-image-compression';
import { ArrowLeft, Trash2 } from 'lucide-react';
import { Button } from '@/components/ui/button';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import {
  backendMessage,
  createComplaint,
  deleteComplaintPhoto,
  getCatalog,
  getComplaint,
  getComplaintPhotoUrl,
  updateComplaint,
  uploadComplaintPhoto,
  type Catalog,
  type ComplaintPhoto,
} from '../api/complaintsApi';
import { CatalogSelects, type CatalogSelection } from '../components/CatalogSelects';

const MAX_PHOTOS = 3;
const MAX_BYTES = 1_048_576;
const DESC_MIN = 10;
const DESC_MAX = 2000;

async function compress(file: File): Promise<File> {
  try {
    return await imageCompression(file, { maxSizeMB: 0.95, maxWidthOrHeight: 1920 });
  } catch {
    return file; // backend valida tamanho/tipo
  }
}

export function ComplaintFormPage() {
  const { id } = useParams<{ id: string }>();
  const isEdit = !!id;
  const navigate = useNavigate();
  const fileRef = useRef<HTMLInputElement>(null);

  const [catalog, setCatalog] = useState<Catalog | null>(null);
  const [selection, setSelection] = useState<CatalogSelection>({
    typeId: '',
    subtypeId: '',
    locationId: '',
  });
  const [fallback, setFallback] = useState<Record<string, string>>({});
  const [locationDetail, setLocationDetail] = useState('');
  const [description, setDescription] = useState('');
  const [photos, setPhotos] = useState<ComplaintPhoto[]>([]);
  const [photoUrls, setPhotoUrls] = useState<Record<string, string>>({});
  const [pending, setPending] = useState<{ file: File; url: string }[]>([]);
  const [saving, setSaving] = useState(false);
  const [uploading, setUploading] = useState(false);

  useEffect(() => {
    getCatalog()
      .then(setCatalog)
      .catch(() => toast.error('Erro ao carregar as opções do chamado.'));
  }, []);

  useEffect(() => {
    if (!id) return;
    getComplaint(id)
      .then((c) => {
        setSelection({ typeId: c.typeId, subtypeId: c.subtypeId, locationId: c.locationId });
        setFallback({
          typeId: c.typeId,
          typeName: c.typeName,
          subtypeId: c.subtypeId,
          subtypeName: c.subtypeName,
          locationId: c.locationId,
          locationName: c.locationName,
        });
        setLocationDetail(c.locationDetail ?? '');
        setDescription(c.description);
        setPhotos(c.photos);
        c.photos.forEach((p) =>
          getComplaintPhotoUrl(id, p.id)
            .then((url) => setPhotoUrls((prev) => ({ ...prev, [p.id]: url })))
            .catch(() => {})
        );
      })
      .catch(() => toast.error('Erro ao carregar o chamado.'));
  }, [id]);

  const photoCount = isEdit ? photos.length : pending.length;

  const pickPhoto = async (raw: File | null) => {
    if (!raw) return;
    if (fileRef.current) fileRef.current.value = '';
    if (photoCount >= MAX_PHOTOS) {
      toast.error(`Máximo de ${MAX_PHOTOS} fotos por chamado.`);
      return;
    }
    const file = await compress(raw);
    if (file.size > MAX_BYTES) {
      toast.error('A foto ficou maior que 1MB mesmo comprimida. Tente outra.');
      return;
    }
    if (!isEdit || !id) {
      setPending((prev) => [...prev, { file, url: URL.createObjectURL(file) }]);
      return;
    }
    setUploading(true);
    try {
      const photo = await uploadComplaintPhoto(id, file);
      setPhotos((prev) => [...prev, photo]);
      getComplaintPhotoUrl(id, photo.id)
        .then((url) => setPhotoUrls((prev) => ({ ...prev, [photo.id]: url })))
        .catch(() => {});
    } catch (err) {
      toast.error(backendMessage(err, 'Erro ao enviar a foto.'));
    } finally {
      setUploading(false);
    }
  };

  const removePending = (index: number) => {
    setPending((prev) => {
      const next = [...prev];
      const [removed] = next.splice(index, 1);
      if (removed) URL.revokeObjectURL(removed.url);
      return next;
    });
  };

  const removePhoto = async (photoId: string) => {
    if (!id) return;
    try {
      await deleteComplaintPhoto(id, photoId);
      setPhotos((prev) => prev.filter((p) => p.id !== photoId));
    } catch (err) {
      toast.error(backendMessage(err, 'Erro ao remover a foto.'));
    }
  };

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!selection.typeId || !selection.subtypeId || !selection.locationId) {
      toast.error('Escolha tipo, subtipo e local.');
      return;
    }
    const desc = description.trim();
    if (desc.length < DESC_MIN) {
      toast.error('A descrição precisa ter pelo menos 10 caracteres.');
      return;
    }
    const body = {
      ...selection,
      locationDetail: locationDetail.trim() || null,
      description: desc,
    };
    setSaving(true);
    try {
      if (isEdit && id) {
        await updateComplaint(id, body);
        toast.success('Chamado atualizado.');
        navigate(`/chamados/${id}`);
        return;
      }
      const created = await createComplaint(body);
      let failed = 0;
      for (const p of pending) {
        try {
          await uploadComplaintPhoto(created.id, p.file);
        } catch {
          failed += 1;
        }
        URL.revokeObjectURL(p.url);
      }
      if (failed > 0) {
        toast.error(`Chamado aberto, mas ${failed} foto(s) não foram enviadas. Adicione na edição.`);
      } else {
        toast.success('Chamado aberto.');
      }
      navigate(`/chamados/${created.id}`, { replace: true });
    } catch (err) {
      toast.error(backendMessage(err, 'Erro ao salvar o chamado.'));
    } finally {
      setSaving(false);
    }
  };

  return (
    <main className="mx-auto max-w-2xl space-y-4 p-4">
      <Button asChild variant="ghost" className="min-h-[44px] px-2">
        <Link to={isEdit && id ? `/chamados/${id}` : '/chamados'}>
          <ArrowLeft aria-hidden="true" /> Voltar
        </Link>
      </Button>

      <Card>
        <CardHeader>
          <CardTitle>{isEdit ? 'Editar chamado' : 'Abrir chamado'}</CardTitle>
        </CardHeader>
        <CardContent>
          <form onSubmit={handleSubmit} className="space-y-4" noValidate>
            {catalog ? (
              <CatalogSelects
                catalog={catalog}
                value={selection}
                onChange={setSelection}
                fallback={fallback}
              />
            ) : (
              <p className="text-sm text-muted-foreground">Carregando opções…</p>
            )}
            <div className="space-y-2">
              <Label htmlFor="location-detail">Complemento do local (opcional)</Label>
              <Input
                id="location-detail"
                maxLength={200}
                placeholder="Ex.: 5º andar, perto do elevador"
                value={locationDetail}
                onChange={(e) => setLocationDetail(e.target.value)}
              />
            </div>
            <div className="space-y-2">
              <Label htmlFor="description">Descrição</Label>
              <textarea
                id="description"
                rows={5}
                maxLength={DESC_MAX}
                value={description}
                onChange={(e) => setDescription(e.target.value)}
                className="flex w-full rounded-md border border-input bg-background px-3 py-2 text-sm ring-offset-background focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2"
              />
              <p className="text-right text-xs text-muted-foreground">
                {description.length}/{DESC_MAX}
              </p>
            </div>
            <Button type="submit" disabled={saving} className="min-h-[44px] w-full">
              {saving ? 'Salvando…' : isEdit ? 'Salvar alterações' : 'Abrir chamado'}
            </Button>
          </form>
        </CardContent>
      </Card>

      <Card>
        <CardHeader>
          <CardTitle className="text-lg">
            Fotos ({photoCount}/{MAX_PHOTOS})
          </CardTitle>
        </CardHeader>
        <CardContent className="space-y-3">
          <p className="text-sm text-muted-foreground">
            Fotografe só o problema: não inclua pessoas, placas de carro ou documentos.
          </p>
          <Label htmlFor="photo">Adicionar foto</Label>
          <input
            id="photo"
            ref={fileRef}
            type="file"
            accept="image/jpeg,image/png,image/webp"
            disabled={uploading || photoCount >= MAX_PHOTOS}
            className="block min-h-[44px] w-full rounded-md border border-input bg-background px-3 py-2 text-sm disabled:cursor-not-allowed disabled:opacity-50"
            onChange={(e) => pickPhoto(e.target.files?.[0] ?? null)}
          />
          {photoCount >= MAX_PHOTOS && (
            <p className="text-sm text-muted-foreground">Limite de {MAX_PHOTOS} fotos atingido.</p>
          )}
          {uploading && <p className="text-sm text-muted-foreground">Enviando…</p>}
          <ul className="grid grid-cols-3 gap-2">
            {(isEdit
              ? photos.map((p) => ({ key: p.id, url: photoUrls[p.id], onRemove: () => removePhoto(p.id) }))
              : pending.map((p, i) => ({ key: p.url + i, url: p.url, onRemove: () => removePending(i) }))
            ).map((p, i) => (
              <li key={p.key} className="space-y-1">
                <div className="aspect-square overflow-hidden rounded-md border bg-muted">
                  {p.url && (
                    <img src={p.url} alt={`Foto ${i + 1}`} className="h-full w-full object-cover" />
                  )}
                </div>
                <Button
                  type="button"
                  variant="outline"
                  className="min-h-[44px] w-full"
                  onClick={p.onRemove}
                  aria-label={`Remover foto ${i + 1}`}
                >
                  <Trash2 aria-hidden="true" />
                </Button>
              </li>
            ))}
          </ul>
        </CardContent>
      </Card>
    </main>
  );
}
```

```tsx
import { useCallback, useEffect, useState } from 'react';

  previewBatch,

  type ComplaintBatch,

export function ComplaintForwardPage() {
  const [ready, setReady] = useState<Complaint[]>([]);
  const [selected, setSelected] = useState<Set<string>>(new Set());
  const [text, setText] = useState('');
  const [confirming, setConfirming] = useState(false);
  const [busy, setBusy] = useState(false);
  const [batches, setBatches] = useState<ComplaintBatch[]>([]);

  const load = useCallback(() => {
    adminQueue(['READY'], 0)
      .then((p) => {
        const list = p.content.map((r) => r.complaint);
        setReady(list);
        setSelected(new Set(list.map((c) => c.id)));
      })
      .catch(() => toast.error('Erro ao carregar os chamados prontos.'));
    listBatches().then(setBatches).catch(() => {});

    setConfirming(false);

    setSelected((prev) => {
      const next = new Set(prev);
      if (next.has(id)) next.delete(id);
      else next.add(id);
      return next;
    });
    setText(''); // seleção mudou: texto antigo não vale mais

      setBusy(false);
    }

      toast.success('Texto copiado.');
    } catch {
      toast.error('Não foi possível copiar. Selecione o texto e copie manualmente.');
    }

    setBusy(true);
    try {
      const batch = await createBatch(ids);
      toast.success(`${batch.complaintCount} chamado(s) encaminhado(s).`);
    } catch (err) {
      toast.error(backendMessage(err, 'Erro ao confirmar o envio.'));
    } finally {
      setBusy(false);
      load();
    }

  return (

      <Button asChild variant="ghost" className="min-h-[44px] px-2">
```

```java
  public void updateSyndicResponse(UUID actor, String text, Instant now) {
    requireStatus(ComplaintStatus.FORWARDED, ComplaintStatus.RESOLVED);
    String t = text == null || text.isBlank() ? null : text.strip();
    if (t != null && t.length() > DESCRIPTION_MAX) {
```
